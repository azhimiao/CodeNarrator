# 术语说明

状态是按名字保存中间对象的共享字典，引用表示多个位置指向同一对象。动态分派是先读步骤名称，再查登记表决定用哪个处理对象。候选框描述目标矩形，掩膜为每个像素提供区域权重。交并比是两框交叠面积占联合面积的比例；非极大值抑制优先留高分、去掉重叠候选。图文特征是模型生成的数值表示，归一化点积用于衡量匹配，但并非正确概率。提示示例通过上下文引导生成，不会在导入时自动执行。token 是模型分割文字的单位。梯度用于学习，本项目关闭它进行推理，不训练这些模型。Notebook 内核保存变量，乱序或重复执行会影响状态；本译本按保存顺序说明。

温度调节生成时对不同候选文字概率差异的处理，较高通常让采样选择更多样，但不会保证程序正确。top-p 是按概率从高到低保留累计概率达到阈值的一组候选再采样；零点五不是只生成一半文字。张量是带形状的多维数值数组，图像像素、文字编码和模型特征均可装入；搬到设备指把这些数据放到 CPU 或 GPU 所用内存。二范数是向量各分量平方和的平方根；按它归一化使向量长度为一，让点积主要比较方向，从而得到余弦相似度。批次是一次一起交给模型处理的多项输入。

GrabCut 用像素颜色和邻近关系迭代区分前景与背景。它的标签零、一、二、三分别表示确定背景、确定前景、可能背景、可能前景，不是四种透明度。通常应把零和二映到背景、把一和三映到前景；本项目直接将标签转浮点用于混合，因此不能把它自动解释成已正确二值化。高斯模糊把邻域像素按距离加权平均以减小细节，半径控制作用范围。双线性插值根据附近像素插算缩放后的值，所以分割掩膜缩放后不一定只含零和一。

修补的引导尺度控制生成向提示文字靠拢的强度，这里取七点五；它不是成功概率，且更强不保证更好图像。fp16 指用十六位浮点数保存部分模型数值以减少内存，并非把图像限制成十六种颜色。评估模式切换模型中训练与推理行为不同的部分，关闭梯度则不记录用于反向学习的计算；两者目的不同，本项目都没有由此训练模型。NaN 是无法表示为普通数值的浮点结果；专用空值 None 表示没有对象，空列表表示有一个列表但其中没有项，三者不能互换。

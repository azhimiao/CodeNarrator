## 逐行分派步骤并返回最后一行结果

### 概览

创建时把任务名交给注册过程，缺省 nlvr，立即获得已实例化的步骤字典。

### 完整过程

创建时把任务名交给注册过程，缺省 nlvr，立即获得已实例化的步骤字典。执行一行时先仅解析步骤名称并打印它，按名称在字典中找解释器，调用其执行并传入是否检查。整段执行收到字符串时，以该文字和传入初始状态创建程序；收到其他对象时仅断言它是 Program，此路径不会采用另外传入的 init_state，沿用对象已有状态。对指令列表先逐行创建小程序，每个都直接复用整段程序的同一个状态对象。

准备一个水平分隔线作为展示起点，再按保存顺序执行全部小程序。检查模式逐行取得结果和展示，将展示与分隔线相接；普通模式只取得结果。结束后返回最后一行的结果与完整共享状态，检查模式再加整段展示。它没有看见 RESULT 就停止，也没有跳过空行、重试、异常捕获、状态复制或失败回滚。如果中途失败，后续行不执行，但已写状态仍留在调用者的初始对象里。空文本会拆出一个空行而非零步，解析通常在读取固定符号位置时失败；手工把指令表改为空时，最后结果变量也未赋值。

## 用少量示例提示生成整段程序

### 概览

创建时从环境变量 OPENAI_API_KEY 设置旧客户端全局密钥，保存调用者提供的提示构造过程，默认温度零点七、top-p 零点五、概率聚合方式 mean。

### 完整过程

创建时从环境变量 OPENAI_API_KEY 设置旧客户端全局密钥，保存调用者提供的提示构造过程，默认温度零点七、top-p 零点五、概率聚合方式 mean。生成时先把输入交给提示构造过程，将所得文字作为提示请求旧补全接口：模型 text-davinci-003、最多五百一十二个 token、频率与出现惩罚零、仅一条补全，并请求每个 token 的一个对数概率候选。取第一条结果计算概率指标，再仅去掉生成文字两端的换行，保留其他空白，返回程序文本和指标。它不验证程序、不自动修错，也不先运行再按结果重新生成。

概率计算在第一条补全的 token 列表里从前往后找结束符，遇到即停，用它的下标作为切片终点，取结束符之前的对数概率。mean 对这些值取平均后求自然指数；sum 求和后再求指数，其他聚合名抛未实现错误。没有找到结束符时，下标仍是最后一个 token 的位置，切片实际漏掉最后一个 token。空 token 列表时下标未赋值；结束符精确文字是 <|endoftext|>，只按 token 文字是否完全相等判定。首个就是结束符时切片为空：在 NumPy 的默认数值和告警配置下，mean 为空平均产生非数 NaN，并发出运行时告警，对 NaN 求指数仍是 NaN；sum 的空和为零，指数为一。这不是空 token 列表：列表完全没有 token 时，前面下标根本未赋值，先出现未绑定局部变量错误。若调用方把告警提升为异常或改了数值错误策略，空平均也可能中止。这是客户端提供的生成概率统计，不是视觉结论正确概率。接口、提示构造、响应字段和计算错误均不在本类捕获。

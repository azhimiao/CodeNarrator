# 按置信度去掉重叠候选框

空框列表直接返回两个空列表。否则把框与分数转成 NumPy 数组，分别取得左上右下坐标，面积按闭区间计算：宽为右减左加一，高也加一。按分数升序取得索引。每轮拿最后一个即最高分索引，保存原列表中该框和分数，然后对其余候选计算横纵交集端点，负的交集宽高截成零，交面积除以两框面积之和减交面积，得到交并比。仅保留交并比严格小于阈值的剩余候选，所以恰好等于阈值也被抑制。反复选择直到索引耗尽，按选择顺序返回框和分数。它不验证输入长度、退化面积或阈值；相同分数的顺序依赖数组排序行为。坐标加一规则与 Pillow 的右下排他裁图约定不同。文件还导入 cv2，但本算法没有使用它。

# 数据说明

初始状态是由入口创建的字典，图像存于 IMAGE 或 LEFT、RIGHT。Program 和每行小程序都引用它，解释器对它逐步增加文字答案、计数、框、对象和图像；失败不恢复旧值。普通定位的框伴随 _IMAGE 展示图，Loc2 却只存带 box、category 的对象。分割与人脸对象还含 mask 和实例编号。选择后的列表复用原对象，分类添加 class 与 class_score 会反映到源列表；修补阈值化 mask 会改写源数组。RESULT 只读指定项，不建立左侧输出名。最终返回最后一行结果和整个状态。表达式的格式化字典是另建的，但不构成执行隔离。图像框坐标有闭区间计算与 Pillow 排他裁剪的混用，具体边界见各过程。

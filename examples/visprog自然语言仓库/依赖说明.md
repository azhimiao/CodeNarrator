# 依赖说明

环境声明 Python 三点十、OpenAI 客户端零点二十三点零、Transformers 四点二十七点二、Diffusers 零点十四点零、Pillow 九点二点零等，详见环境译文。生成器请求 text-davinci-003，列表步骤请求 text-davinci-002；这些是固定代码中的旧补全调用，不能承诺今天服务仍可用。视觉处理分别依赖 BLIP 问答、OWL-ViT 开放词汇框检测、MaskFormer 分割、CLIP 图文特征、人脸检测与 Stable Diffusion 图像修补。处理器负责将输入转换成张量，模型从预训练标识加载并可能联网取权重；设评估模式与关闭梯度不会保证预测正确。CLIP 这里用自己归一化特征后的点积作为余弦分数，不是校准概率。修补中的白掩膜指需要生成替换的区域、黑色表示保留的区域，项目另有阈值和缩放处理。torch、NumPy 未独立锁定；修补无 CPU 回退、展示有 Linux 字体路径，都是运行条件。本文已经展开项目实际如何调用依赖，权重内部训练细节不属于此仓库实现。

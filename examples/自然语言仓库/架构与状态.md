# 架构与状态

输入为可按顺序遍历的记录，每项预期支持名称读取。得分可以缺失或为空，此时跳过；标识只在记录被选中后才必需。筛选结果是新集合，但复用原记录对象，保持顺序与重复。报告再把标识转为文本，形成独立列表及数量。成功结果包含报告和序列化文本；失败结果只包含失败标记及异常类型原因。配置最低得分标注浮点数，上限标注整数，运行时只做范围检查，未强制类型。

## 协调筛选与报告任务

本模块连接配置、筛选和报告过程。成功时返回结构化报告与文本；只对两类处理错误给出失败结果。

## 形成并序列化报告

本模块把选中的记录整理为数量和标识列表，再通过标准库转换为可传递的文本。

[深入阅读相关实现](%E6%A8%A1%E5%9D%97/report.py.md#section-1)

## 按得分顺序筛选记录

本模块负责保留达到最低得分的记录，达到数量上限后立即停止。它保留原记录的引用，不复制内容。

[深入阅读相关实现](%E6%A8%A1%E5%9D%97/select_records.py.md#section-1)

## 确定筛选规则

本模块用数据类保存最低得分和最多保留条数，并在配置创建时拒绝非法范围。配置对象默认禁止重新赋值字段。

[深入阅读相关实现](%E6%A8%A1%E5%9D%97/settings.py.md#section-1)

## 组件关系

协调筛选与报告任务 → 确定筛选规则：省略配置时创建默认规则；范围检查在记录处理的捕获范围之外。

协调筛选与报告任务 → 按得分顺序筛选记录：按输入顺序筛选并提前停止，结果复用记录对象。

协调筛选与报告任务 → 形成并序列化报告：将选中标识转为文本后构建和序列化报告，特定失败由任务入口转换。

## 从记录到报告的一次任务

1. 调用者提供记录和可选配置。省略配置时创建最低得分零点八、上限三的默认规则。按输入顺序跳过缺失得分和低分记录，保留恰好等于或高于最低得分的项；保留数量达到上限时停止。按保留顺序提取必需标识并转成文本，形成数量及标识列表，再编码为 JSON 文本。全部成功才返回成功标记、报告与文本。处理中的键错误或类型错误会改为仅包含失败标记和原因类别的结果；其他错误向调用者传播。

失败边界：具体失败边界与是否传播见本流程正文。

# 行为验收

这些是本版本实际记录的问题、预期和对照结果。复核方式如下，不代表已经开展人类理解实验。

Agent 对照本固定示例源码及完整译文核查；不是独立人类理解实验

## 默认配置如何选择达标记录？

源码行为预期：按输入顺序保留前三条得分至少零点八的记录，不按得分排序。

译文对照结果：按输入顺序保留前三条得分至少零点八的记录，不按得分排序。

检查方式：Agent 对照本固定示例源码及完整译文核查；不是独立人类理解实验

## 数量上限一点五会被拒绝吗？

源码行为预期：不会；它通过范围检查，筛选在保留两条时达到停止条件。

译文对照结果：不会；它通过范围检查，筛选在保留两条时达到停止条件。

检查方式：Agent 对照本固定示例源码及完整译文核查；不是独立人类理解实验

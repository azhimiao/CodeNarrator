# 跨模块流程

## 从记录到报告的一次任务

调用者提供记录和可选配置。省略配置时创建最低得分零点八、上限三的默认规则。按输入顺序跳过缺失得分和低分记录，保留恰好等于或高于最低得分的项；保留数量达到上限时停止。按保留顺序提取必需标识并转成文本，形成数量及标识列表，再编码为 JSON 文本。全部成功才返回成功标记、报告与文本。处理中的键错误或类型错误会改为仅包含失败标记和原因类别的结果；其他错误向调用者传播。

# 按得分顺序筛选记录

本模块负责保留达到最低得分的记录，达到数量上限后立即停止。它保留原记录的引用，不复制内容。

## 本文件的处理过程

- [筛选的职责与前提](#section-1)

- [依次检查并保留](#section-2)

- [返回对象与失败传播](#section-3)

<a id="section-1"></a>

## 筛选的职责与前提

### 概览

接收记录序列、最低得分和数量上限。

### 完整过程

任务流程把输入记录、最低得分和数量上限交给本过程。它不自行检查配置范围，而是使用提供的值。模块载入时只定义处理过程，不执行筛选。记录预期为支持按名称读取字段的对象，得分预期能够与最低得分比较。

### 进一步理解

输入可以是可逐条取得记录的对象，并不限定为某一种列表。取记录的过程本身也可能失败。

<a id="section-2"></a>

## 依次检查并保留

### 概览

跳过缺失或为空的得分，保留大于等于最低得分的记录，达到上限后停止。

### 完整过程

先建立空结果集合，再按输入迭代顺序逐条获取记录。对每条记录读取得分；字段不存在或值为空时跳过。否则与最低得分比较，低于要求则不保留，恰好相等或更高则把原记录放到结果末尾。每保留一条后，检查已保留条数是否大于等于上限；满足时立即结束，不再检查余下输入。不满足则继续。输入耗尽或提前结束后，返回结果。默认上限三表示最多保留前三条达标记录，而不是得分最高的三条。这里的空值特指 Python 中表示没有值的专用状态，不包括空字符串、空列表或零。空字符串会进入得分比较，通常因不能与数值阈值比较而导致类型错误。输入的得分字段名称是 score，标识字段名称是 id。

### 进一步理解

数量限制只在成功保留后检查。输入为空或没有达标项时返回空集合。缺少得分与得分为零不同：零参与比较，而缺少得分会被跳过。

<a id="section-3"></a>

## 返回对象与失败传播

### 概览

返回新集合，其中各项仍是原记录；本过程不捕获异常。

### 完整过程

返回的集合是新建的，但其中的记录没有复制。因此通过结果修改某条记录的字段会影响同一条输入记录。本过程没有主动改写记录，也没有去重，重复出现的达标记录可被重复保留并计入上限。得分不可比较可能引发类型错误，记录不支持所需读取操作可能引发属性错误，输入迭代也可能出错；这些失败均向任务流程传播。

### 进一步理解

新集合与内容副本是两件事。添加到集合的是对原对象的引用，多个位置可以指向同一条记录。

## 输出提示文字

### 概览

入口不接收参数，输出一句提示，然后正常结束。

### 完整过程

模块定义一个无参数入口。调用它时，向标准输出写入 Call your main application code here，随后附加换行。它没有返回业务结果，正常完成时返回 Python 的专用空值状态。此模块不自行调用入口；安装元数据将名为 sample 的命令连接到这里。它不调用加一工具，也不读取包内数据。输出设备失败时的异常未在这里捕获。

### 进一步理解

标准输出通常表现为终端显示，也可以被外部重定向。包初始化文件在导入时定义函数，并不意味着自动运行这个函数。

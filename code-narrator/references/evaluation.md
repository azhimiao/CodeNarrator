# 如何验收

先做工具验证，再做语义核查和独立阅读检查。三者不可相互替代。

1. validate 检查范围内失败、不支持文件、结构覆盖、分块与邻域指纹、源码快照、关键字段、证据、组件归属、状态/关系引用、正常/边界/失败问题和译文复核指纹；render 再检查最终内部链接。
2. 用源码核查具体行为：默认参数、边界、循环顺序、空值、异常传播、输入修改和依赖效果。至少准备一组有准确答案的问题，不能让同一个生成模型单纯给自己打分。
3. 阅读者只取得自然语言目录，不取得源码、构建记录或额外补充回答。检查是否能据此回答问题，并指出自然语言章节。

适合的问题包括：输入如何产生，某边界是否保留，重复数据如何处理，何时停止，错误到哪里处理，配置如何覆盖，外部能力究竟做什么，输出是否共享原对象。

缺失内容应回写到正文再测试。只能依赖源码答出的问题算翻译缺口。“术语已列出”“单元已关联”不能消除此缺口。

真实人类参与者研究需实际安排和记录；独立 Agent 的只读检查只能记为 Agent 检查。不要混用名称，不要虚构受试者、耗时、正确率或统计结论。

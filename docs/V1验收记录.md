正文保留了实际实现差异，包括：五种前后裁图只是别名、上下裁图无框时取左半图、RESULT 不停止或建立左侧状态、Loc2 检查返回值与状态类型不同、分类原地写字段与非正分空项、修补改写原掩膜、COUNT 展示失败晚于写入、概率末 token 遗漏、坏提示中的错变量和表达式。

独立阅读后进一步发现提示内未转义的 Disney's。使用 CPython v3.10.14 官方词法源码和当前 Python 3.12.14 分别核查并记录不同结果，详见 [词法证据](visprog-tokenizer-evidence.json)。依赖含义按版本化的一手资料核查，见 [依赖契约核查](依赖契约核查.md)。

## 仅自然语言的独立阅读

第一位独立 Agent 只获得成品目录，全文阅读 28 份 Markdown，回答 8 组涉及入口、状态、定位、裁图、分类、概率、计数和错误示例的问题，指出 6 类缺口。问题与原始观察保存在 [首轮报告](独立阅读检查-首轮.json)。

缺口已回写正文：展开全部示例、精确区分 None 与空列表、补全概率退化输入、解释采样与视觉术语、给出词法符号顺序及确定版本的行为、增加跨步骤与提示到契约的直接导航。第二位独立 Agent 只读自然语言目录，对 6 组细节问题核查，实际完整阅读 9 份相关文档并覆盖全部 55 个示例；最后又对残余的版本表述和导航作定点复查，确认两项关闭，55 个示例的 230 个契约链接均到达正确章节，本轮记录的 gaps 为空。结果见 [最终阅读报告](独立阅读检查-最终.json)。这表示已检查的问题没有残余缺口，不代表证明任何可能问题都已覆盖。

这些是 Agent 阅读检查，不是人类参与者实验，也不构成对未见源码的语义准确率评估。阅读者回答与源码行为预期、离线契约测试结合使用；没有把模型给自己打分作为完成依据。

## 一致性检查的实质边界

保留了“所有结构编号仍在、正文却全换成空泛文字”的反例。新版会因译文指纹变化拒绝沿用旧复核；若生成者虚假刷新复核声明，确定性工具仍可能通过。结果见 [回归反例](coverage-regression-result.json)。因此不能把 2105 个结构映射当成 2105 项语义正确证明。

V1 完成的是可复用 Skill、真实科研仓库的完整译本、工程检查和上述具体阅读问题。其他语言与内核、任意仓库的已证明准确率、完整视觉模型端到端运行、真实学生的学习时间与理解效果不属于本次已验证结论。

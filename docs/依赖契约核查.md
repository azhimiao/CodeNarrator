# VisProg 相关依赖契约核查

日期：2026-10-31。以仓库 environment.yaml 声明的版本为依据；不假定当前最新版或远端模型仍与历史实现兼容。

| 契约 | 核查依据与本项目使用 |
|---|---|
| 开放词汇检测 | [Transformers 4.27.2 OWL-ViT 文档](https://huggingface.co/docs/transformers/v4.27.2/en/model_doc/owlvit)：文字与图片共同编码，检测后处理按目标图像尺寸得到框；VisProg 随后还有自己的整数截断、严格阈值筛选与 NMS。 |
| 图文特征 | [Transformers 4.27.2 CLIP 文档](https://huggingface.co/docs/transformers/v4.27.2/en/model_doc/clip)：公开图像和文字特征接口；VisProg 自行归一化后取点积，因此译文称为余弦相似度，而不是正确概率。 |
| 图像修补 | [Diffusers 0.14.0 修补文档](https://huggingface.co/docs/diffusers/v0.14.0/en/api/pipelines/stable_diffusion/inpaint)：白掩膜为重绘、黑色为保留；VisProg 使用自己的阈值、填充、裁边与回缩，不能只用依赖接口名代替这些实现。 |
| 掩膜细化 | [OpenCV 4.6.0 GrabCut 教程](https://docs.opencv.org/4.6.0/d8/d83/tutorial_py_grabcut.html)：零、一、二、三为确定背景、确定前景、可能背景、可能前景；项目直接作混合权重的行为与常见的二值映射区别已写入正文。 |
| 空聚合 | [NumPy 1.23 求和契约](https://numpy.org/doc/1.23/reference/generated/numpy.sum.html)：空和为零。另在当前可用 NumPy 2.3.5 实际检查空平均的指数为 NaN（默认配置发出 RuntimeWarning）、空和的指数为一；输入项目未锁 NumPy，译文同时说明告警配置可改变失败方式。 |
| 单引号错误的词法行为 | 使用 [CPython v3.10.14 的官方 tokenize.py](https://github.com/python/cpython/blob/v3.10.14/Lib/tokenize.py) 对固定源文件的解析函数作隔离验证：冰雪奇缘示例的 question 在 Disney 之后被截断，尾部形成额外参数。当前运行时 Python 3.12.14 则报告 TokenError。输入项目声明 Python 3.10，译文分别说明；完整结果保存在 visprog-tokenizer-evidence.json。 |

这些版本化一手文档用于核对传入数据的含义。项目调用顺序、共享引用、参数值和异常边界以固定提交源码为依据。模型权重内部算法未翻译，也未开展服务可用性或预测准确性实验。
